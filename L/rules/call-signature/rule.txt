call-signature
kind: soundness

Claim. If the lab accepts a program, every call is on a value whose type has a call signature the call was
checked against.

Counterexample in plain TypeScript. typeof value === 'function' narrows an unknown to Function, and Function has
no call signature. resolveCallExpression calls it anyway: isUntypedFunctionCall sends a callee with no call or
construct signatures that is assignable to Function to resolveUntypedCall, whose anySignature takes any
arguments and returns any. A constructor, such as Map, is a function, and calling one without new throws a
TypeError. The release accepts the witness below, and Node crashes on it.

Obligation 1, call with a signature: TS2349 (TypeScript's code)
  Statement. A call may be accepted only if the callee's type has a call signature that the arguments are
  checked against. Function promises none, because typeof 'function' is true of a constructor, which can't be
  called.
  Mechanism. isUntypedFunctionCall no longer takes a callee that is assignable to Function and has no signature
  of its own, so resolveCallExpression, resolveTaggedTemplateExpression and resolveDecorator report it as not
  callable. Its any half is the any rule's: an any callee is read as unknown, which has no signature either.
  Why it suffices. isUntypedFunctionCall is the only way a call reaches resolveUntypedCall's anySignature; every
  other call resolves against a signature of the callee's type.
  In Lean. ../../lean/Top.lean's typeof 'function' test refines nothing, and Vacuity.lean proves the witness's
  program untypable there. mutants/funCall, TypeScript's narrowing to a callable, is refuted by calling a
  class.
  Witnesses:
    chk-call-narrowed-function.ts      an unknown narrowed by typeof 'function', then called
    chk-function-type-call.ts          a constructor held as Function, called
    chk-call-function-tagged.ts        a constructor held as Function, used as a template's tag
  Rejected sound code, because Function promises no call:
    function-held-arrow.ts             an arrow function held as Function, called
  Controls:
    typed-call.ts                      a callee with a call signature

Obligation 2, new.target in a plain call: TS2722 (TypeScript's code)
  Statement. new.target in a function, which may be called without new, is the function or undefined.
  Mechanism. checkNewTargetMetaProperty adds undefined to its type in a function; in a constructor it stays the
  class, which can't be called without new.
  Why it suffices. new.target is typed there and nowhere else.
  Witnesses:
    chk-new-target-plain-call.ts       new.target called in a function called without new
  Controls:
    new-target-checked.ts              a function that tells new.target from undefined
